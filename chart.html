CSV Data Format

Your CSV file must include columns for Date, Open, High, Low, Close.

You can add custom columns and control where they render using this header format:
ColumnName:Pane:Type

  • Pane: Top, Middle, Bottom, HIDDEN
  • Type: Line, Histogram, ColorLine

Note: To use a ColorLine, provide a second hidden column named ColumnName_Dir with values 1 (Uptrend) or 0 (Downtrend).

Note: Using the HIDDEN pane (e.g., RSI:HIDDEN) makes the column available in the Filter Modal, but skips drawing it on the chart!

Example: $.Close > 100 or $.Macd > $.MacdSignal
